DBSCAN & PCA — Advanced Unsupervised Learning

DBSCAN (Density-Based Clustering)

DBSCAN groups points that are closely packed together, marking outliers as noise. Unlike K-Means, it doesn't require specifying the number of clusters and can find arbitrarily-shaped clusters.

📍

Core Point

A point with at least min_samples neighbors within radius eps. Forms the core of a cluster.

🔗

Border Point

Within eps of a core point but doesn't have enough neighbors itself. Belongs to a cluster but isn't core.

❌

Noise Point (Outlier)

Not within eps of any core point. Labeled as -1. DBSCAN is excellent for anomaly detection because of this.

🔢

Hyperparameters

eps: max distance to be considered neighbor. min_samples: min points to form a core point. Use elbow of k-distance graph to choose eps.

dbscan_pca.py

From Scratch — Linear & Logistic Regression

Implementing algorithms from scratch builds deep intuition that cannot be gained from high-level APIs alone. Below are full implementations of Linear Regression (with MSE loss & Ridge L2) and Logistic Regression (with Binary Cross-Entropy loss) using only pure NumPy and gradient descent.

📐

Linear Regression Math

Hypothesis: $\hat{y} = Xw + b$.
Loss: $J(w, b) = \frac{1}{2n}\|Xw + b - y\|_2^2 + \frac{\lambda}{2}\|w\|_2^2$.
Gradients: $\nabla_w J = \frac{1}{n}X^T(\hat{y} - y) + \lambda w$, $\nabla_b J = \frac{1}{n}\sum(\hat{y} - y)$.

📉

Logistic Regression Math

Hypothesis: $\hat{p} = \sigma(Xw + b) = \frac{1}{1 + e^{-(Xw+b)}}$.
Loss: $-\frac{1}{n}\sum [y\log\hat{p} + (1-y)\log(1-\hat{p})]$.
Gradients: Identical algebraic form $\frac{1}{n}X^T(\hat{p} - y)$, but $\hat{p}$ is squashed via sigmoid!

⚙️

The Optimization Loop

1. Forward pass $\to$ 2. Compute Loss $\to$ 3. Analytical Gradients (chain rule) $\to$ 4. Parameter update: $w \leftarrow w - \alpha \nabla_w, b \leftarrow b - \alpha \nabla_b$.

from_scratch_regression.py
import numpy as np

# ==============================================================================
# 1. LINEAR REGRESSION FROM SCRATCH (GRADIENT DESCENT + L2 REGULARIZATION)
# ==============================================================================
class LinearRegressionScratch:
    def __init__(self, lr=0.01, epochs=1000, l2=0.0):
        self.lr, self.epochs, self.l2 = lr, epochs, l2
        self.w, self.b = None, 0.0
        self.losses = []

    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.w = np.zeros(n_features)
        self.b = 0.0
        self.losses = []

        for _ in range(self.epochs):
            # 1. Forward pass: y_pred = X @ w + b
            y_pred = X @ self.w + self.b
            error = y_pred - y

            # 2. Mean Squared Error + L2 penalty
            mse = (1 / (2 * n_samples)) * np.sum(error**2)
            loss = mse + (self.l2 / 2) * np.sum(self.w**2)
            self.losses.append(loss)

            # 3. Analytical gradients
            dw = (1 / n_samples) * (X.T @ error) + self.l2 * self.w
            db = (1 / n_samples) * np.sum(error)

            # 4. Gradient descent step
            self.w -= self.lr * dw
            self.b -= self.lr * db

    def predict(self, X):
        return X @ self.w + self.b

    def r2_score(self, X, y):
        y_pred = self.predict(X)
        ss_res = np.sum((y - y_pred)**2)
        ss_tot = np.sum((y - np.mean(y))**2)
        return 1.0 - (ss_res / (ss_tot + 1e-8))

# ==============================================================================
# 2. LOGISTIC REGRESSION FROM SCRATCH (SIGMOID + CROSS-ENTROPY LOSS)
# ==============================================================================
class LogisticRegressionScratch:
    def __init__(self, lr=0.01, epochs=1000, l2=0.0):
        self.lr, self.epochs, self.l2 = lr, epochs, l2
        self.w, self.b = None, 0.0
        self.losses = []

    def _sigmoid(self, z):
        return 1 / (1 + np.exp(-np.clip(z, -250, 250)))  # Clipped for numerical stability

    def fit(self, X, y):
        n, d = X.shape
        self.w = np.zeros(d)
        self.b = 0.0
        self.losses = []

        for _ in range(self.epochs):
            # Forward pass
            z      = X @ self.w + self.b
            y_pred = self._sigmoid(z)           # Calibrated probabilities 0..1

            # Binary cross-entropy loss with L2 regularization
            loss = -np.mean(y * np.log(y_pred + 1e-8) +
                             (1-y) * np.log(1-y_pred + 1e-8))
            loss += (self.l2 / 2) * np.sum(self.w**2)
            self.losses.append(loss)

            # Analytical gradients
            error = y_pred - y
            dw = (1/n) * (X.T @ error) + self.l2 * self.w
            db = (1/n) * error.sum()

            # Update parameters
            self.w -= self.lr * dw
            self.b -= self.lr * db

    def predict_proba(self, X):
        return self._sigmoid(X @ self.w + self.b)

    def predict(self, X, threshold=0.5):
        return (self.predict_proba(X) >= threshold).astype(int)

    def accuracy(self, X, y):
        return np.mean(self.predict(X) == y)

🧠 Key Deep Dive Takeaway Forward pass (predictions) → Loss calculation (MSE vs Log-Loss) → Backward pass (analytical gradients via matrix calculus) → Weight update. This is the exact foundational loop that autograd engines like PyTorch automate for billion-parameter neural networks.
