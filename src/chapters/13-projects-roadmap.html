Learning Roadmap

Follow this path step by step. Don't skip ahead â€” each step builds on the previous one.

1

Month 1-2: Python + Libraries

Master Python basics, NumPy, Pandas, and Matplotlib. Complete at least 50 practice problems. This is your foundation.

2

Month 2-3: Machine Learning

Learn scikit-learn. Understand regression, classification, clustering. Build 3-4 complete ML projects. Learn data preprocessing thoroughly.

3

Month 3-4: Deep Learning

Learn Keras/TensorFlow or PyTorch. Understand neural networks, CNNs for images, RNNs for text. Build image classifier and text classifier.

4

Month 4-5: NLP + Generative AI

Learn text preprocessing, transformers, Hugging Face. Understand LLMs, prompt engineering, and AI APIs.

5

Month 5-6: RAG, Agents & Deployment

Build RAG applications, create AI agents, deploy models with Flask/Streamlit. Build a portfolio of 5+ projects.
