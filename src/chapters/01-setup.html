Virtual Environments (Best Practice)

A virtual environment is an isolated space for your project. This prevents library versions from clashing across different projects (e.g., Project A needs TensorFlow 2.10, Project B needs TensorFlow 2.15).

terminal 
# 1. Create a virtual environment named 'myenv'
python -m venv myenv

# 2. Activate it
# On Windows:
myenv\Scripts\activate
# On Mac/Linux:
source myenv/bin/activate

# 3. Now install your libraries
pip install scikit-learn pandas

# 4. Deactivate when done
deactivate
ðŸ’¡ Pro Tip Never install everything globally. Always create a virtual environment for each new AI project. This is how professionals work.

Your First AI Program

Let's write a tiny ML program to prove everything works. This program predicts exam scores based on hours studied.

first_ai.py 
# Your first AI program! ðŸŽ‰
from sklearn.linear_model import LinearRegression
import numpy as np

# Data: hours studied â†’ exam score
hours = np.array([[1],[2],[3],[4],[5],[6],[7],[8]])
scores = np.array([40, 50, 55, 65, 70, 75, 85, 90])

# Train the model (it learns the pattern)
model = LinearRegression()
model.fit(hours, scores)

# Predict: what score for 9 hours of study?
prediction = model.predict([[9]])
print(f"Predicted score for 9 hours: {prediction[0]:.1f}")
# Output: Predicted score for 9 hours: 95.4

print("âœ… Your AI setup works! You're ready to learn.")
