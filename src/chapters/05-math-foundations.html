Vectors & Matrices

Every dataset, neural network weight, and word embedding is ultimately just numbers arranged in arrays. Vectors and matrices are the language of ML.

➡️

Vector

A 1D array of numbers. A single data point with 3 features (age, salary, experience) is a vector: [25, 60000, 2]. Length = number of features = dimensionality.

🔢

Matrix

A 2D array of numbers. Your whole dataset is a matrix of shape (n_samples × n_features). Each row = one data point, each column = one feature.

📐

Dot Product

The core operation of ML: sum of element-wise products. In linear regression: prediction = w · x (weights dot features). Measures alignment/similarity.

🔄

Matrix Multiply

Each element (i,j) of the result = dot product of row i with column j. Powers every neural network forward pass. Rule: (m×k) × (k×n) → (m×n).

numpy — vectors and matrices
import numpy as np

# Vectors
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

dot = np.dot(v1, v2)            # 1*4 + 2*5 + 3*6 = 32
magnitude = np.linalg.norm(v1)  # sqrt(1^2+2^2+3^2) = 3.74

# Cosine similarity (used in NLP embeddings)
cos_sim = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
print(f"Cosine similarity: {cos_sim:.4f}")  # 0.9746

# Matrices
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

C = np.dot(A, B)         # Matrix multiplication
# [[1*5+2*7, 1*6+2*8], [3*5+4*7, 3*6+4*8]] = [[19,22],[43,50]]

print(A.T)               # Transpose: flip rows <-> columns
print(np.linalg.inv(A))  # Inverse: A * A^-1 = Identity

# Broadcast: operations on mismatched shapes (NumPy auto-expands)
X = np.random.randn(100, 5)  # 100 samples, 5 features
w = np.array([0.1, 0.2, -0.3, 0.5, 0.8])  # weights
predictions = X @ w              # @ = matrix multiply, shape (100,)

Statistics & Probability

Statistics helps you understand your data. Probability underpins every ML model — classifiers output probabilities, loss functions are based on probability theory.

statistics essentials
import numpy as np

data = np.array([2, 4, 4, 4, 5, 5, 7, 9])

# Central tendency
mean   = np.mean(data)    # 5.0  — average, sensitive to outliers
median = np.median(data)  # 4.5  — middle value, robust to outliers

# Spread / dispersion
variance = np.var(data)   # 4.0  — avg squared deviation from mean
std_dev  = np.std(data)   # 2.0  — sqrt(variance), same units as data

# Correlation: -1 (perfect inverse) to +1 (perfect direct)
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])
corr = np.corrcoef(x, y)[0, 1]  # 0.87 — strong positive correlation

# Probability distributions
from scipy import stats

normal    = stats.norm(loc=0, scale=1)   # Standard normal (mean=0, std=1)
bernoulli = stats.bernoulli(p=0.3)       # Coin flip with P(heads)=0.3

print(normal.pdf(0))    # 0.3989 — probability density at x=0
print(normal.cdf(1.96)) # 0.9750 — P(X <= 1.96)

Conditional Probability & Bayes' Theorem

Bayes' theorem is the mathematical foundation for many ML models including Naive Bayes classifiers, Bayesian optimization, and probabilistic reasoning.

P(A|B) = P(B|A) × P(A) / P(B)
📊

P(A|B) — Posterior

Probability of A given that B occurred. What we want to find. E.g., P(spam | email contains "free money")

🔍

P(B|A) — Likelihood

How likely is B if A is true? P("free money" in email | email is spam). Estimated from training data.

📌

P(A) — Prior

Initial belief before seeing evidence. P(email is spam) = 20% of all emails are spam. Based on base rates.

📐

P(B) — Evidence

Total probability of observing B. Normalizing constant. Often computed as Σ P(B|Aᵢ)P(Aᵢ) over all classes.

Bayes' theorem — medical test example
# Medical test example:
# Disease prevalence (prior): 1% of population
# Test sensitivity: 99% (correctly detects disease)
# Test specificity: 95% (correctly flags healthy as healthy)

p_disease  = 0.01   # Prior: P(Disease)
p_no_dis   = 0.99   # P(No Disease)
p_pos_dis  = 0.99   # Sensitivity: P(Positive | Disease)
p_pos_nodis= 0.05   # False positive rate: P(Positive | No Disease)

# Total P(Positive) = law of total probability
p_positive = (p_pos_dis * p_disease) + (p_pos_nodis * p_no_dis)
# = 0.99*0.01 + 0.05*0.99 = 0.0099 + 0.0495 = 0.0594

# Bayes: P(Disease | Positive test)
p_disease_given_pos = (p_pos_dis * p_disease) / p_positive
print(f"P(Disease | Positive test): {p_disease_given_pos:.1%}")
# Only 16.7%! Counterintuitive — because disease is rare (base rate matters!)

Derivatives & Gradients

A derivative measures how much a function's output changes when you change its input. Gradients are derivatives for multi-variable functions. These are how ML models learn.

📉

Derivative

Rate of change. f'(x) = slope of the curve at point x. If f(x) = x², then f'(x) = 2x. At x=3, slope = 6.

🏔️

Gradient

Vector of partial derivatives. ∇f(w₁, w₂) = [∂f/∂w₁, ∂f/∂w₂]. Points in the direction of steepest increase.

⛓️

Chain Rule

If f(g(x)), then df/dx = (df/dg)(dg/dx). Fundamental for backpropagation — how gradients flow through neural network layers.

🔁

Partial Derivative

Derivative with respect to ONE variable, treating others as constants. ∂/∂w₁ means "how much does output change if I nudge only w₁?"

computing gradients
import numpy as np

# Manual gradient: MSE Loss for linear regression
# Loss = (1/n) * Σ(y_pred - y_true)^2
# d(Loss)/d(w) = (2/n) * X^T * (X*w - y)

def compute_gradients(X, y, w):
    n = len(y)
    y_pred = X @ w                        # Forward pass
    error  = y_pred - y                   # Residuals
    grad_w = (2/n) * X.T @ error         # Gradient of loss w.r.t. weights
    loss   = np.mean(error**2)           # MSE loss
    return grad_w, loss

# Example
X = np.array([[1, 2], [1, 3], [1, 4]])  # 3 samples, 2 features
y = np.array([5, 7, 9])
w = np.zeros(2)                          # Start with zero weights

grad, loss = compute_gradients(X, y, w)
print(f"Loss: {loss:.2f}, Gradient: {grad}")
# Gradient tells us: increase w[0] and w[1] to reduce loss

Gradient Descent — How Models Learn

Gradient descent is the optimization algorithm used to train virtually every ML model. The idea: move the model's parameters in the direction that reduces the loss function.

w = w - α × ∇L(w)    (α = learning rate)
1

Initialize weights randomly

Start with random (or zero) weights. The model knows nothing yet.

2

Forward pass — make predictions

Run the current weights through the model. Compute the loss (how wrong you are).

3

Backward pass — compute gradients

Calculate the gradient of the loss with respect to every weight. "Which direction makes the loss increase?"

4

Update weights

Move weights opposite to gradient (downhill). Step size controlled by learning rate α.

5

Repeat until convergence

After many iterations (epochs), the loss stops decreasing. The model has learned.

gradient descent from scratch
import numpy as np

# Gradient Descent for Linear Regression (from scratch!)
class LinearRegressionGD:
    def __init__(self, lr=0.01, epochs=1000):
        self.lr, self.epochs = lr, epochs
        self.losses = []

    def fit(self, X, y):
        n, d = X.shape
        self.w = np.zeros(d)  # Initialize weights to 0
        self.b = 0            # Bias term

        for _ in range(self.epochs):
            # Forward pass
            y_pred = X @ self.w + self.b
            error  = y_pred - y

            # Gradients
            dw = (2/n) * X.T @ error
            db = (2/n) * error.sum()

            # Update weights (step downhill!)
            self.w -= self.lr * dw
            self.b -= self.lr * db

            # Track loss
            loss = np.mean(error**2)
            self.losses.append(loss)

    def predict(self, X):
        return X @ self.w + self.b

# Train it!
np.random.seed(42)
X = np.random.randn(100, 1)
y = 3 * X.flatten() + 2 + np.random.randn(100) * 0.5  # True: w=3, b=2

model = LinearRegressionGD(lr=0.1, epochs=500)
model.fit(X, y)
print(f"Learned w={model.w[0]:.3f}, b={model.b:.3f}")  # ~3.0, ~2.0
print(f"Final loss: {model.losses[-1]:.4f}")
