Iterators & Generators (yield)

In machine learning, datasets are frequently tens or hundreds of gigabytesâ€”far too large to load into RAM all at once. Iterators and generators allow you to stream data lazily on-demand with constant $O(1)$ memory consumption.

â†»

The Iterator Protocol

An iterable is any object you can loop over (lists, dicts, strings). An iterator is the object that produces items one by one via __iter__() and __next__(), raising StopIteration when exhausted.

âš¡

The yield Keyword

Unlike return, which terminates a function and dumps all items into RAM, yield pauses function execution, saves local variable states, and emits a single item. Execution resumes right after the yield on the next call.

ðŸ’¾

Memory: O(1) vs O(N)

A list comprehension [x for x in range(10_000_000)] allocates ~800MB in RAM. A generator expression (x for x in range(10_000_000)) uses only ~200 bytes regardless of dataset size!

generators_and_streaming.py
# 1. Understanding iter() and next()
nums = [10, 20, 30]
it = iter(nums)
print(next(it))  # 10
print(next(it))  # 20
print(next(it))  # 30
# next(it) now raises StopIteration!

# 2. Generator Function with yield
def count_up_to(max_val):
    count = 1
    while count <= max_val:
        yield count       # Pauses and returns value
        count += 1        # Resumes here next time

counter = count_up_to(3)
for n in counter:
    print(n)              # 1, 2, 3

# 3. Generator Expressions (Lazy Comprehensions)
gen_exp = (x**2 for x in range(1_000_000))  # Instant, ~200 bytes RAM!
print(next(gen_exp))      # 0
print(next(gen_exp))      # 1

# 4. Realistic ML Pipeline: Streaming Mini-Batches (PyTorch DataLoader intuition)
import numpy as np

def batch_data_generator(X, y, batch_size=32, shuffle=True):
    """Yields batches of features and targets without duplicating memory"""
    n_samples = len(X)
    indices = np.arange(n_samples)
    if shuffle:
        np.random.shuffle(indices)
    
    for start_idx in range(0, n_samples, batch_size):
        batch_idx = indices[start_idx : start_idx + batch_size]
        yield X[batch_idx], y[batch_idx]

# Simulate 1,000 samples
X_dummy = np.random.randn(1000, 10)
y_dummy = np.random.randint(0, 2, 1000)

# Train loop streaming batches
for epoch in range(2):
    for batch_x, batch_y in batch_data_generator(X_dummy, y_dummy, batch_size=128):
        # In PyTorch: loss = model(batch_x); loss.backward(); optimizer.step()
        pass
print("Successfully streamed batches with zero memory blowup!")

# A realistic ML example: Min-Max normalization
def normalize(data):
    """Scale values to 0-1 range (Min-Max normalization)"""
    min_val = min(data)
    max_val = max(data)
    return [(x - min_val) / (max_val - min_val) for x in data]

raw = [10, 50, 30, 80, 20]
print(normalize(raw))  # [0.0, 0.57, 0.29, 1.0, 0.14]

Classes & OOP (Object-Oriented Programming)

Classes bundle data and functions together. PyTorch uses classes heavily for defining neural networks. Understanding OOP will help you read ML library source code.

classes.py 
class MLModel:
    """A simple class to demonstrate OOP concepts"""

    def __init__(self, name, accuracy=0.0):
        # __init__ runs when you create a new object
        self.name = name
        self.accuracy = accuracy
        self.trained = False

    def train(self, data):
        print(f"Training {self.name} on {len(data)} samples...")
        self.trained = True
        self.accuracy = 0.95

    def predict(self, input_data):
        if not self.trained:
            print("âš ï¸ Model not trained yet!")
            return None
        return f"Prediction for {input_data}"

    def __str__(self):
        return f"Model({self.name}, acc={self.accuracy:.2%})"

# Using the class
model = MLModel("RandomForest")
model.train([1,2,3,4,5])
print(model)            # Model(RandomForest, acc=95.00%)
print(model.predict(42)) # Prediction for 42

Type Annotations & Python Modules

Modern production machine learning requires robust, maintainable code. Type hints (PEP 484) make your data shapes and function signatures explicit, catching costly bugs before training runs. Python modules and packages organize your codebase cleanly.

🏷️

Type Hints (typing)

Specify expected types for arguments and return values using primitives (int, float, str) or generic containers from the typing module (List, Dict, Optional, Union, Callable).

📦

Modules & Packages

A module is a .py file. A package is a directory with an __init__.py file. Use if __name__ == "__main__": to ensure test code only runs when executed directly, not on import.

🛡️

Static Type Checking

Tools like mypy inspect your code statically: mypy pipeline.py flags type mismatches (e.g. passing a string instead of a NumPy array) before hours of training compute are wasted.

from typing import List, Dict, Tuple, Optional, Union, Callable, Any
import numpy as np

# Type aliases for readability in ML pipelines
Vector = List[float]
Matrix = List[Vector]

# 1. Annotated Function Signatures
def calculate_metrics(
    y_true: np.ndarray, 
    y_pred: np.ndarray, 
    threshold: float = 0.5
) -> Dict[str, float]:
    """Computes accuracy and threshold summary with strict type safety"""
    binary_preds = (y_pred >= threshold).astype(int)
    acc = float(np.mean(y_true == binary_preds))
    return {"accuracy": acc, "threshold": threshold}

# 2. Optional and Union Types
def load_weights(
    checkpoint_path: Optional[str] = None, 
    device: Union[str, int] = "cpu"
) -> Dict[str, Any]:
    if checkpoint_path is None:
        print(f"Initializing random weights on device {device}")
        return {"layer1": np.zeros((10, 10))}
    print(f"Loading weights from {checkpoint_path}")
    return {}

# 3. Higher-order function with Callable
def apply_transform(
    data: np.ndarray, 
    transform_fn: Callable[[np.ndarray], np.ndarray]
) -> np.ndarray:
    return transform_fn(data)

Decorators (Advanced)

Decorators modify the behavior of a function without changing its code. They are heavily used in ML frameworks (like PyTorch and Flask) for routing, logging, or timing execution.

decorators.py 
import time

# Define a decorator to measure execution time
def timer_decorator(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"Function '{func.__name__}' took {end - start:.4f} seconds")
        return result
    return wrapper

# Apply the decorator using @
@timer_decorator
def train_dummy_model(epochs):
    for _ in range(epochs):
        time.sleep(0.01)  # Simulate training
    return "Training complete"

print(train_dummy_model(50))
# Output:
# Function 'train_dummy_model' took 0.5052 seconds
# Training complete

Testing with pytest

Writing tests ensures your code works correctly and prevents regressions when you refactor. pytest is the industry-standard testing framework for Python.

test_ml_utils.py
# Install: pip install pytest
# File: test_ml_utils.py

import pytest
import numpy as np

# --- Function to test ---
def normalize(arr):
    """Scale array to [0, 1]"""
    min_v, max_v = arr.min(), arr.max()
    if max_v == min_v:
        raise ValueError("Cannot normalize constant array")
    return (arr - min_v) / (max_v - min_v)

# --- Tests ---
def test_normalize_basic():
    arr = np.array([0, 5, 10])
    result = normalize(arr)
    assert result[0] == 0.0
    assert result[-1] == 1.0

def test_normalize_min_max():
    arr = np.array([2, 4, 6])
    result = normalize(arr)
    assert np.isclose(result.max(), 1.0)
    assert np.isclose(result.min(), 0.0)

def test_constant_array_raises():
    with pytest.raises(ValueError):
        normalize(np.array([5, 5, 5]))

# --- Parametrize: run one test with multiple inputs ---
@pytest.mark.parametrize("arr,expected_max", [
    (np.array([1, 2, 3]), 1.0),
    (np.array([-5, 0, 5]), 1.0),
])
def test_max_is_one(arr, expected_max):
    assert normalize(arr).max() == expected_max

# Run all tests: pytest test_ml_utils.py -v
