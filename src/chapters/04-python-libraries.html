NumPy â€” Fast Array Computing

NumPy is the foundation of ML in Python. Every ML library (scikit-learn, TensorFlow, PyTorch) works with NumPy arrays under the hood. It's 50-100x faster than Python lists for math operations.

numpy_basics.py 
import numpy as np

# Creating arrays
a = np.array([1, 2, 3, 4, 5])
b = np.zeros((3, 3))        # 3Ã—3 matrix of zeros
c = np.ones((2, 4))         # 2Ã—4 matrix of ones
d = np.random.rand(3, 3)   # random 3Ã—3 matrix (0 to 1)
e = np.arange(0, 10, 2)     # [0, 2, 4, 6, 8]
f = np.linspace(0, 1, 5)   # [0, 0.25, 0.5, 0.75, 1.0]

# Array shape and info
x = np.array([[1, 2, 3], [4, 5, 6]])
print(x.shape)    # (2, 3) â€” 2 rows, 3 columns
print(x.ndim)     # 2 â€” number of dimensions
print(x.dtype)    # int64
print(x.size)     # 6 â€” total number of elements

# Vectorized math â€” no loops needed!
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(a + b)      # [5, 7, 9]
print(a * b)      # [4, 10, 18] â€” element-wise
print(a @ b)      # 32 â€” dot product (1*4 + 2*5 + 3*6)

# Reshape â€” CRITICAL for ML (changing data dimensions)
flat = np.arange(12)       # [0,1,2,...,11]
mat = flat.reshape(3, 4)  # 3Ã—4 matrix
print(mat[1, :])      # row 1: [4, 5, 6, 7]
print(mat[:, 2])      # column 2: [2, 6, 10]

# Statistical functions (used constantly in ML)
data = np.array([4, 7, 13, 2, 9])
print(np.mean(data))   # 7.0 â€” average
print(np.std(data))    # standard deviation
print(np.max(data))    # 13
print(np.argmax(data)) # 2 (index of max value)
print(np.sum(data))    # 35

Pandas â€” Data Tables & Analysis

Pandas gives you Excel-like tables in Python called DataFrames. You'll use it to load CSV files, clean data, and explore datasets before training any model.

pandas_basics.py 
import pandas as pd

# Create DataFrame from dict
data = {
    "name": ["Alice", "Bob", "Charlie", "Diana"],
    "age":  [25, 30, 35, 28],
    "score": [88, 92, 79, 95]
}
df = pd.DataFrame(data)

# Reading a CSV file (most common real-world use)
# df = pd.read_csv("dataset.csv")

# Exploring the data â€” ALWAYS do this first!
df.head()           # first 5 rows
df.tail(3)          # last 3 rows
df.shape            # (rows, columns) â†’ (4, 3)
df.info()           # column types + null counts
df.describe()       # statistics: mean, std, min, max

# Selecting data
df["age"]              # single column â†’ Series
df[["name", "score"]]  # multiple columns
df.iloc[0]              # first row by index
df.loc[df["age"] > 28]  # filter: rows where age > 28

# Handling missing values â€” VERY important in ML
df.isnull().sum()      # count NaN per column
df.dropna()             # remove rows with any NaN
df.fillna(0)            # replace NaN with 0
df["age"].fillna(df["age"].mean())  # fill with column mean

# Sorting
df.sort_values("score", ascending=False)  # highest score first

# Adding a new column
df["grade"] = df["score"].apply(lambda s: "A" if s >= 90 else "B")

# GroupBy â€” aggregate by category
# df.groupby("department")["salary"].mean()

Advanced Pandas (Joins & Pivot Tables)

Real-world data rarely comes in one perfect table. You need to merge datasets and reshape them to extract insights.

pandas_advanced.py 
import pandas as pd

# --- Merging DataFrames (SQL-like JOIN) ---
users = pd.DataFrame({"id": [1, 2, 3], "name": ["Alice", "Bob", "Charlie"]})
purchases = pd.DataFrame({"user_id": [1, 2, 2], "amount": [50, 100, 200]})

# Merge based on matching IDs (Inner join by default)
merged_df = pd.merge(users, purchases, left_on="id", right_on="user_id")
print(merged_df)

# --- Pivot Tables ---
# Great for summarizing data (like Excel Pivot Tables)
data = pd.DataFrame({
    "department": ["Sales", "Sales", "IT", "IT"],
    "year": [2023, 2024, 2023, 2024],
    "budget": [500, 600, 800, 900]
})
pivot = pd.pivot_table(data, values="budget", index="department", columns="year")
print(pivot)

Practical Project: Data Analytics Dashboard

Let's build a mini-script that reads student data, analyzes it, and visualizes the results. This combines NumPy, Pandas, and Matplotlib.

1

Generate Data

We'll use NumPy to generate a synthetic dataset of 100 students.

2

Analyze with Pandas

Calculate class averages, pass rates, and find the top performers.

3

Visualize

Create a histogram of scores to see the distribution.

project_analytics.py 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 1. Generate Data
np.random.seed(42)
data = {
    "Student_ID": range(1, 101),
    "Study_Hours": np.random.normal(5, 2, 100).clip(0, 10),
    "Exam_Score": np.random.normal(65, 15, 100).clip(0, 100)
}
df = pd.DataFrame(data)

# 2. Analyze
df["Passed"] = df["Exam_Score"] >= 50
print("--- Class Report ---")
print(f"Average Score: {df['Exam_Score'].mean():.1f}")
print(f"Pass Rate: {df['Passed'].mean() * 100:.1f}%")
print("\nTop 3 Students:")
print(df.nlargest(3, "Exam_Score"))

# 3. Visualize
plt.figure(figsize=(8, 5))
plt.hist(df["Exam_Score"], bins=15, color='#7c6ff7', edgecolor='black')
plt.axvline(df["Exam_Score"].mean(), color='red', linestyle='dashed', linewidth=2, label="Mean")
plt.title("Exam Score Distribution")
plt.xlabel("Score")
plt.ylabel("Number of Students")
plt.legend()
plt.show()
